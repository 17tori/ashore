# Как пользоваться Ashore

## 1. Резюме

Скачайте резюме с hh.ru («Мои резюме» → «Скачать» → PDF или Word) и загрузите в разделе «Резюме».
Проверьте навыки и опыт: удалите лишнее, добавьте недостающее и нажмите «Всё верно, подтвердить».
Оценка вакансий и письма опираются только на эти факты.

## 2. Профиль поиска

В «Профилях поиска» укажите должности, город, формат работы, зарплату и пороги оценки. Профилей
может быть несколько: например, «Python junior» и «Стажировки».

## 3. Вакансии

Без подключённого API hh.ru вакансии добавляются двумя способами:

* **Закладка «В Ashore»**: «Вакансии» → «Закладка для hh.ru», перетащите кнопку на панель закладок.
  Откройте вакансию на hh.ru и нажмите закладку.
* **Вручную**: «Добавить вакансию», вставьте ссылку и текст.

Каждая вакансия получает оценку 0–100 с объяснением: что совпало, чего не хватает, какие риски.
Решение системы можно изменить кнопками «Подходит / Подумать / Не подходит».

## 4. Отклик

«Подготовить отклик» → проверьте письмо → «Откликнуться». Если API недоступен, откроется окно:
скопируйте письмо, откройте форму на hh.ru, вставьте и отправьте, затем нажмите «Я отправил(а) отклик».
Ответ работодателя отмечается в разделе «Отклики».

## 5. Автоматизация

* **Ручной** — всё по кнопке.
* **С подтверждением** — подходящие вакансии сами попадают в очередь с готовым письмом.
* **Автоотклики** — только при подключённом API hh.ru, после подтверждения правил.

«Остановить всё» в шапке ставит паузу и возвращает очередь на подтверждение.

## 6. Поднятие резюме

hh.ru позволяет бесплатно поднимать резюме раз в 4 часа. Ashore напомнит, когда можно, а после
поднятия на сайте нажмите «Я поднял(а) резюме на hh.ru».

## 7. Telegram

«Настройки» → «Привязать Telegram». Бот присылает уведомления и умеет `/stats`, `/queue`, `/pause`, `/resume`.

## 8. Данные

«Настройки» → «Мои данные»: выгрузка всего в JSON и удаление аккаунта.
