## Что нужно для реальной интеграции с hh.ru

1. Зарегистрировать приложение на dev.hh.ru (адрес возврата: `{PUBLIC_BASE_URL}/api/hh/oauth/callback`).
2. Заполнить `HH_CLIENT_ID`, `HH_CLIENT_SECRET`, `HH_USER_AGENT`.
3. Подключить аккаунт в настройках и нажать «Проверить доступ». Таблица возможностей покажет,
   что hh.ru реально разрешил.
