# Ashore Careers — AI Job Agent

Персональный помощник для поиска работы на hh.ru: разбирает резюме, оценивает вакансии с
объяснением, пишет сопроводительные письма только из ваших фактов, ведёт отклики и аналитику.

**Работает без API hh.ru.** С декабря 2025 соискательский API hh.ru закрыт для сторонних приложений,
поэтому основной сценарий — закладка в браузере или ручной импорт и отклик на сайте в один клик.
Если появятся ключи API, поиск и отклики через API включатся для тех операций, которые hh.ru
действительно разрешит ([подробности](docs/hhru_api_capabilities.md)).

## Возможности

* Резюме PDF/DOCX/TXT → структурированный профиль, у каждого факта источник и подтверждение
* Оценка вакансий 0–100: жёсткие фильтры, настраиваемые веса, риски, защита от мошеннических вакансий
* Письма: 6 шаблонов, тон и длина, проверка на выдуманные навыки и стаж
* Отклики без дублей, со статусом «нужна проверка», если результат неизвестен
* Режимы: ручной, с подтверждением, автоотклики по подтверждённым правилам; «Остановить всё»
* Напоминания о поднятии резюме, Telegram-бот, аналитика воронки
* Шифрование токенов и резюме, выгрузка и удаление данных (152-ФЗ)

## Стек

FastAPI · SQLAlchemy 2 · Alembic · PostgreSQL · Redis · ARQ · Next.js 15 · TypeScript · Tailwind · Docker Compose · Caddy

## Быстрый старт

```bash
cp .env.example .env   # заполнить POSTGRES_PASSWORD, ENCRYPTION_KEYS, PUBLIC_BASE_URL, SITE_ADDRESS
docker compose up -d --build
```
