Ashore Careers: запуск на своём компьютере (Windows)
====================================================

Это личная сборка. Всё работает только на этом компьютере: адрес http://localhost:8080
открывается лишь здесь, данные хранятся в Docker на этом диске и никуда не отправляются.

ЧТО НУЖНО ОДИН РАЗ
------------------
1. Windows 10 или 11 (64-бит), 8 ГБ памяти, 10 ГБ свободного места.
2. Docker Desktop: https://www.docker.com/products/docker-desktop/
   Установить с настройками по умолчанию (WSL 2), перезагрузить компьютер,
   один раз открыть Docker Desktop и принять условия.
3. Распаковать этот архив в постоянную папку, например C:\Ashore
   (не запускать прямо из архива).

ЗАПУСК
------
Двойной щелчок по start-ashore.bat.
Первый запуск собирает программу, это 5-15 минут. Потом откроется браузер.
Дальше запуск занимает около минуты.

При первом входе зарегистрируйтесь: учётная запись создаётся только в этой копии.
В настройках можно загрузить примеры вакансий: они помечены «[Пример]».

ОСТАНОВКА
---------
stop-ashore.bat. Данные сохраняются, при следующем запуске всё на месте.
Если не останавливать, Ashore будет работать в фоне, пока запущен Docker Desktop.

РЕЗЕРВНАЯ КОПИЯ
---------------
backup-ashore.bat создаёт папку backups\<дата> с базой и файлом env.local.txt.
В env.local.txt ключи шифрования: без них копия базы бесполезна, а с ними
к данным есть полный доступ. Храните эту папку как пароли.

ВАЖНО
-----
* Файл .env.local создаётся при первом запуске и содержит ключи. Не удаляйте его
  и никому не пересылайте: без него сохранённые данные не расшифровать.
* Без ключей hh.ru программа работает в ручном режиме: вакансии добавляются
  закладкой в браузере или вставкой текста, отклик отправляется в один клик
  на сайте hh.ru. Автоматические отклики через API появятся, когда будут ключи
  dev.hh.ru (их вписывают в .env.local и перезапускают start-ashore.bat).
* Telegram-бот в локальной сборке не работает: ему нужен публичный адрес в интернете.
* Если порт 8080 занят, поменяйте ASHORE_PORT и PUBLIC_BASE_URL в .env.local.

ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
Журнал работы: открыть PowerShell в папке Ashore и выполнить
  docker compose -f docker-compose.local.yml --env-file .env.local logs --tail 100
